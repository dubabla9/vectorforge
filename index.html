FAQ

Questions, answered.

Do I need to create an account?
No. The core workflow is designed to work without signup.
Are my images uploaded to a server?
The planned core workflow processes images in the browser, so there is no need for a normal upload-storage pipeline.
Does the validator guarantee stock-platform approval?
No. It checks technical conditions only. Final acceptance depends on the platform's current requirements and review.
Will advanced features require payment?
The core tool is intended to remain free. Advanced features can be offered later as an optional Pro layer.
